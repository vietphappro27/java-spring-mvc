# 👟 P Shoes — E-Commerce System

A full-stack shoe e-commerce platform built with **Spring Boot 3.2** and **Spring MVC**, featuring server-side rendering with JSP, session-based authentication, and VNPay payment integration.

## 🚀 Features

### **Customer Portal**

- **Product Catalog**: Browse shoes with search and filtering by criteria
- **Product Details**: View product variants by size and stock
- **Shopping Cart**: Add, update, and remove items from cart
- **Checkout & Payment**: Place orders and pay via **VNPay** sandbox
- **Order History**: View past orders
- **Account Management**: Update profile and change password
- **User Authentication**: Register, login with form-based authentication

### **Admin Dashboard**

- **Dashboard Overview**: Centralized admin panel
- **Product Management**: CRUD products with image upload and size/stock variants
- **User Management**: Create, update, delete user accounts
- **Order Management**: View, update, and delete orders
- **Role-based Access**: Admin-only routes under `/admin/**`

### **Technical Features**

- **Spring MVC**: Server-side rendering with JSP views
- **Spring Security**: Form login, BCrypt password hashing, role-based authorization
- **Spring Session JDBC**: Persistent session storage in database
- **JPA/Hibernate**: ORM with MySQL
- **Jakarta Validation**: Server-side input validation
- **File Upload**: Local image storage for product photos
- **VNPay Integration**: Online payment gateway for Vietnam
